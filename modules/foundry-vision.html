画像を理解し、画像を生成する

Foundry で画像への質問、画像生成、動画生成を試し、結果をアプリで扱う流れを学びます。

画像とテキストを入力する

画像入力に対応したモデルをデプロイし、プレイグラウンドで画像と質問を送ります。「この画像を説明して」と「右側のラベルを読み取って」を比べると、指示の粒度で結果が変わることが分かります。Python からは API が要求する形式で画像と文章を同じ入力に含め、返されたテキストを表示します。

画像を生成する

画像生成モデルを選び、被写体、構図、背景、出力サイズなどを指定します。出力は API に応じて画像データや取得先として返ります。「商品の配置は同じで背景だけ変更」など、比較したい条件を一度に一つ変えると差を見やすくなります。

動画を生成する

動画を扱えるモデルには、対応していれば場面、動き、長さ、画角などを指定できます。動画生成は要求を送って後から結果を取得する方式の場合があるため、ステータスと完了後の出力取得を分けて扱います。モデルとリージョンの提供状況は演習で確認します。
