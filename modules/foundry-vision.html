分析と生成でモデルを選ぶ

画像と文章を入力して説明を返すモデル、指示から画像を生成するモデル、動画を生成するモデルでは出力が異なります。必要な入力形式と出力、対応するモデルのデプロイ、出力の検証方法を先に決めます。

マルチモーダル モデルで画像を分析する

画像入力に対応するモデルをデプロイして、Foundry のプレイグラウンドで画像と指示を送ります。「画像を説明して」と「写真にある案内の文字を挙げて」を比べると、出力に必要な指示の違いが分かります。見えない部分を推測していないか、画像と回答を照らし合わせます。

Python からは Responses API のメッセージにテキストと画像を含めます。画像には API が受け付ける URL やデータ形式を使い、返った文章を取得します。ファイル形式、サイズ、認証、モデルが画像入力に対応しているかを順に確認すると、失敗を切り分けやすくなります。

Python の実装例

コードに出てくる環境変数を設定し、指定のライブラリをインストールして実行します。

# pip install openai
import base64
import os
from pathlib import Path
from openai import OpenAI

client = OpenAI(
    base_url=os.environ["AZURE_OPENAI_V1_URL"],
    api_key=os.environ["AZURE_OPENAI_KEY"],
)
photo = base64.b64encode(Path("sample.jpg").read_bytes()).decode("ascii")
response = client.responses.create(
    model=os.environ["VISION_DEPLOYMENT"],
    input=[{
        "role": "user",
        "content": [
            {"type": "input_text", "text": "写真に見える看板の文字を挙げてください。"},
            {"type": "input_image", "image_url": "data:image/jpeg;base64," + photo},
        ],
    }],
)
print(response.output_text)

画像生成モデルを使う

画像生成のプレイグラウンドでは、被写体、視点、背景などを指定します。クライアントから呼び出すときは、使うデプロイと API に応じて出力サイズや品質を指定し、画像データを受け取って表示または保存します。構成によって、画像生成用の呼び出しや Responses API の画像生成ツールを使います。

入力を一つずつ変え、意図した変更を比較します。指定した文字、寸法、図の正確さが重要なら、生成された画像を目視や別の方法で検証します。

動画生成モデルを使う

テキストから動画を生成する場合は、場面に加えて動きや順序を指定します。プレイグラウンドで動きや構図を確認し、API からは出力時間や解像度など対応するオプションを指定します。

REST API が非同期ジョブを使う場合は、動画ジョブを作って ID を受け取り、その ID でステータスを確認し、成功したらコンテンツをダウンロードします。失敗やタイムアウト時の扱いと、生成にかかる時間・費用も考慮します。

演習

Foundry のプレイグラウンドで画像分析と生成を比べ、アプリで出力を受け取ります。

  1. 画像入力可能なモデルにサンプル画像と質問を送ります。回答が写真のどの箇所に対応するかを確認します。
  2. 画像生成用のモデルを選び、「窓辺に白い鉢植えを配置した写真」のような指示で出力し、背景や視点を一つ変更して比べます。
  3. 対応する構成があれば動画生成を試します。API で行う場合はジョブの ID を記録し、完了を確認して出力を取得します。
  4. Python のクライアントでは画像入力とテキストを渡して返った文章を表示します。生成画像では、返却された画像データを保存し意図したサイズか確認します。
