テキストを分析する

Foundry の汎用モデルと Azure Language を使い分け、テキスト分析の結果をアプリに取り込みます。

Foundry で使える分析方法

汎用モデルには「不満点を短くまとめ、根拠の文も添える」のように自由な指示を渡せます。Azure Language には、感情、キーフレーズ、言語、固有表現などの機能があります。試す場合は同じレビューを入力して、どの結果が後続処理に必要か比較します。

Python クライアントを作る

演習で指定される Azure Language のエンドポイントと認証方式を環境に設定します。SDK のテキスト分析クライアントに文章のリストを渡し、文書ごとの結果またはエラーを受け取ります。集計にはラベルに加えて入力の ID を保存し、エラーや再試行も追えるようにします。

エージェントと組み合わせる

エージェントから言語分析を呼び出して使う場合は、ツールで受け取る文章と返却する項目を定義します。「何が不満か」を聞いたときに結果を読み取って説明するか、文章が空なら適切に聞き返すかをポータルで試します。

ミニ演習

100件の口コミを配送・梱包別に集計したい場合、どんな出力が必要ですか。

解答例を見る

口コミ ID、評価対象、感情ラベルを組で出し、複数の評価対象が含まれる場合は個別に記録します。
