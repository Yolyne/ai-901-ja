モデルとエージェントの役割

モデルを直接呼び出すアプリでは、何を入力し、返答を次にどう扱うかをアプリが決めます。エージェントには、ツールを選んで呼び出し、その結果を使って応答する処理を任せられます。どちらでも、目的に合うモデルのデプロイが出発点です。

カタログからモデルを選び、デプロイする

Foundry のモデル カタログでは、提供元、入出力形式、対応機能などを見て候補を選びます。学習資料を要約する用途なら文章が扱えること、写真を説明する用途なら画像入力が扱えることを確かめます。評価データで品質を比較し、リージョン、費用、応答速度、割り当てを確認します。

デプロイ名はクライアントが呼び出すときの識別子で、元のモデル名と異なる場合があります。標準系・プロビジョニング系などの選択肢はモデルやリージョンによって異なります。割り当ての TPM は1分間に扱うトークンの容量に関係し、RPM の制限も呼び出し数に影響します。

プレイグラウンドと Python からモデルを使う

プレイグラウンドでシステム側の指示とユーザー入力を試し、モデルが対応する場合は温度、上位確率によるサンプリング、最大出力トークンなどを調整します。同じ入力で一つずつ条件を変え、形式、内容、分量を確認します。

Python ではプロジェクトや推論用のエンドポイント、認証情報、デプロイ名を揃えます。Foundry の SDK でプロジェクトに接続し、OpenAI 互換のクライアントを取得できる構成では、Responses API にデプロイ名と入力を渡して応答テキストを取り出します。設定値をコードから分け、認証失敗、デプロイ名の間違い、利用上限のエラーを区別します。

Python の実装例

コードに出てくる環境変数を設定し、指定のライブラリをインストールして実行します。

推論用の URL には Azure OpenAI の v1 エンドポイントを指定します。デプロイ名はポータルの表示に合わせます。

# pip install openai
import os
from openai import OpenAI

client = OpenAI(
    base_url=os.environ["AZURE_OPENAI_V1_URL"],
    api_key=os.environ["AZURE_OPENAI_KEY"],
)
response = client.responses.create(
    model=os.environ["CHAT_DEPLOYMENT"],
    instructions="問い合わせを「配送」「返品」「その他」のいずれかに分類してください。",
    input="届いた商品を送り返す方法を知りたいです。",
)
print(response.output_text)

ポータルでエージェントを作り、コードから使う

作成画面でモデルと指示を指定し、業務資料の検索や注文照会など、必要なツールを追加します。テスト画面で普通の質問、ツールが必要な質問、入力が欠けた質問を送って挙動を確かめます。ツールの入力と応答が想定通りかも見ます。

Python からはプロジェクトに認証し、対象のエージェントを指定したクライアントを取得します。会話を作り、その識別子と入力を使って応答を受け取ります。次のメッセージでも同じ会話を指定すれば、先のやり取りを受けた質問を試せます。

Python の実装例

コードに出てくる環境変数を設定し、指定のライブラリをインストールして実行します。

Azure CLI などでサインインし、エージェントへのアクセス権を持つ ID を使います。エージェントは名前で指定します。

# pip install "azure-ai-projects>=2.1.0" azure-identity
import os
from azure.ai.projects import AIProjectClient
from azure.identity import DefaultAzureCredential

with DefaultAzureCredential() as credential, AIProjectClient(
    endpoint=os.environ["FOUNDRY_PROJECT_ENDPOINT"],
    credential=credential,
) as project:
    with project.get_openai_client(agent_name=os.environ["AGENT_NAME"]) as client:
        conversation = client.conversations.create()
        for text in ("返品の手順を教えてください。", "最初にすることだけ教えて。"):
            reply = client.responses.create(
                conversation=conversation.id,
                input=[{"role": "user", "content": text}],
            )
            print(reply.output_text)

演習

Foundry のポータルと Python からモデルを使い、その後エージェントを作成します。

  1. 使うモデルをデプロイし、プレイグラウンドで「問い合わせを配送、返品、その他のどれかに分類」と指示します。対象が不明な入力でも試します。
  2. Azure CLI または演習の指定する認証で接続し、プロジェクトのエンドポイントとデプロイ名をクライアントに設定します。ポータルと同じ依頼を送り、応答文字列を取り出します。
  3. エージェントに役割と利用するツールを設定します。ツールのいる依頼、不要な依頼、不完全な入力を試し、呼び出したツールと結果を確認します。
  4. クライアントからエージェントに同じ内容を送り、会話を引き継いで「その分類の理由も教えて」と尋ねます。
