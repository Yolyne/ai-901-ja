Azure で AI 開発を始める

Azure のリソース構造を理解し、Foundry のポータルとアプリが同じデプロイをどう使うかを学びます。

Azure のリソース

サブスクリプションは課金や利用の境界です。リソース グループで関連リソースをまとめ、リージョンでサービスを配置する場所を選びます。Azure にはコンピューティング、ストレージ、アクセス管理などの機能があり、AI アプリでは通常これらをモデルや AI サービスと組み合わせます。

Foundry でモデルを使えるようにする

Foundry は、モデル、ツール、エージェントを開発・評価・管理するプラットフォームです。プロジェクトを作り、モデル カタログで用途に合うモデルを確認します。対応する入力形式、デプロイ方式、リージョン、割り当て、費用を見てデプロイし、プレイグラウンドで短い入力を試します。

エンドポイントと認証

エンドポイントはアプリが要求を送る接続先です。プロジェクトに接続するときとモデル推論を呼ぶときでは、使う URL やクライアントが異なる場合があります。Azure CLI でサインインして開発時の資格情報を使い、本番では環境に合うマネージド ID と権限を設定する方法があります。

ポータルで試す

公式演習を開き、Azure サブスクリプションと使えるリージョンを確認します。プロジェクトとデプロイを作り、プレイグラウンドで応答を確認します。プロジェクトのエンドポイントとデプロイ名を控え、実習が終わったら演習専用のリソースを整理します。
