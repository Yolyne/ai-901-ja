認識・合成・音声対話を選ぶ

文字起こしが目的なら Speech to Text、読み上げなら Text to Speech、音声で質問して音声で返答を受けるなら音声対話が候補です。録音の一括処理、会話中の応答、必要な言語や待ち時間を考えて構成を選びます。

Azure Speech で音声を認識する

Speech SDK の SpeechConfig で接続先と認証を指定し、AudioConfig でマイクや音声ファイルを入力に設定します。SpeechRecognizer で単発または継続して認識し、文字起こしテキストを受け取ります。単発なら recognize_once_async の結果を待って、認識成功、発話を認識できなかったケース、キャンセルを区別します。

音声ファイルを使うと同じ入力で結果を比較できます。会話には継続認識やストリーム、一括処理にはバッチ処理を検討します。サンプルで句読点や固有名詞、数字が許容範囲に収まるかを確認します。

Python の実装例

コードに出てくる環境変数を設定し、指定のライブラリをインストールして実行します。

# pip install azure-cognitiveservices-speech
import os
import azure.cognitiveservices.speech as speech

config = speech.SpeechConfig(
    endpoint=os.environ["AZURE_SPEECH_ENDPOINT"],
    subscription=os.environ["AZURE_SPEECH_KEY"],
)
config.speech_recognition_language = "ja-JP"
recording = speech.audio.AudioConfig(filename="announcement.wav")
recognizer = speech.SpeechRecognizer(speech_config=config, audio_config=recording)
result = recognizer.recognize_once_async().get()
if result.reason == speech.ResultReason.RecognizedSpeech:
    print(result.text)
else:
    print(result.reason)

マイク・ファイル・継続認識を使い分ける

短い案内音声だけならファイルから単発認識できます。会話を字幕にする場合は継続認識を開始し、認識中の暫定結果と認識済みの確定結果を分けます。前者は画面に表示するだけ、後者は保存すると重複を減らせます。終了時には認識を停止し、キャンセルの情報を確認します。

Azure Speech で文章を読み上げる

SpeechConfig で音声名や出力形式を指定し、SpeechSynthesizer の出力先をスピーカーかファイルに設定します。テキストを渡して非同期で合成し、成功またはキャンセルの結果を確認します。読み、間、速度を指定する必要がある場合は、対応する音声で SSML を使います。

Python の実装例

コードに出てくる環境変数を設定し、指定のライブラリをインストールして実行します。

# pip install azure-cognitiveservices-speech
import os
import azure.cognitiveservices.speech as speech

config = speech.SpeechConfig(
    endpoint=os.environ["AZURE_SPEECH_ENDPOINT"],
    subscription=os.environ["AZURE_SPEECH_KEY"],
)
config.speech_synthesis_voice_name = "ja-JP-NanamiNeural"
audio = speech.audio.AudioOutputConfig(filename="guide.wav")
synthesizer = speech.SpeechSynthesizer(speech_config=config, audio_config=audio)
result = synthesizer.speak_text_async("受付は午前7時30分に始まります。").get()
print(result.reason)

合成結果の保存と確認

読み上げファイルを作る例では、音声名、出力形式、保存先を指定して合成します。処理が成功したと通知されたら WAV を再生し、日付と数字の発音を確認します。失敗した場合はキャンセル詳細を調べ、資格情報、エンドポイントと音声の対応を確認します。

音声対応エージェントと Voice Live

音声対話では、マイクの音を送り、応答音声を連続して受け取ります。Azure Speech の Voice Live を使う構成ではリアルタイムのセッションを開き、双方向に音声やイベントをやり取りします。発話終了、応答開始、割り込み、セッション終了のイベントを区別して、音声の送受信と再生を制御します。

試作時は Foundry のサンプルや公式 SDK を使い、マイクからの入力と応答の再生を一つずつ確認します。文字起こし用 SDK の単発認識と、音声を直接送って応答を受ける処理の違いを押さえます。

Voice Live で一往復する

リアルタイム接続を開いたら、セッションに音声の形式と会話の設定を渡します。マイクから送った音声をもとに、音声応答の断片を逐次受け取って再生します。利用者が応答中に話し始めたら、古い応答を止めて次の発話を扱うなど、送信と再生をイベントで制御します。音声の往復と字幕表示は別々に検証します。

演習

Foundry と Azure Speech で、発話を認識し、その結果を読み上げ、最後に音声から直接応答する流れを試します。

  1. 任意の短い WAV ファイルを用意し、音声認識クライアントに渡します。期待する言葉と文字起こしを比べます。
  2. 読み上げ用のテキストと声を指定し、ファイルまたはスピーカーで合成結果を聴きます。日付や数字の読み方を確認します。
  3. 音声入力が使えるモデルまたは音声対話のプレイグラウンドに同じ質問を送り、内容に沿った応答が返ることを確認します。
  4. リアルタイムのセッションでは、発話中に長めに間を空けたり応答を途中で止めたりして、送信側と再生側の動きを比べます。
